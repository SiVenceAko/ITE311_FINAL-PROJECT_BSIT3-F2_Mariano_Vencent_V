## Project Description

Victoria City Crime Mapping System is a web-based spatial application designed to map, track, and visualize crime incidents across Victoria City. The system uses interactive maps and heatmaps to help users identify high-risk areas, monitor neighborhood safety trends, and filter crime reports by date, type, and location.

- Neighborhood safety monitoring

- Responsive user interface
